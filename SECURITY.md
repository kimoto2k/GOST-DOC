# Безопасность

- Приложение проверяет формат DOCX и ограничивает размер загружаемого файла.
- В этой версии обработка идёт в памяти процесса; приложение намеренно не реализует библиотеку пользовательских документов.
- При публичном размещении файлы пользователей поступают на сервер хостинга. Использование для конфиденциальных документов до отдельной оценки безопасности не рекомендуется.
- Нельзя гарантировать отсутствие сохранения данных на стороне облачного провайдера, в логах или в памяти сервера.
- До широкого запуска нужны политика конфиденциальности, авторизация при необходимости, лимиты запросов, мониторинг, удаление данных и оценка используемого хостинга.
