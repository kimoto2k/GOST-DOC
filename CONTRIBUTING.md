# Совместная разработка

1. Создайте ветку от `main`: `feature/название-задачи`.
2. Добавьте изменение и тест.
3. Запустите `python -m pytest -q`.
4. Откройте Pull Request и попросите владельца проекта проверить.
5. После успешных тестов владелец объединяет Pull Request с `main`.

У владельца должен оставаться доступ администратора. Для соавторов достаточно Write. Защитите `main` через Branch protection / Ruleset по возможностям тарифного плана: требуйте Pull Request и проходящие тесты.

Для изменений алгоритма форматирования добавляйте образцы DOCX без личных данных. Никогда не коммитьте файлы пользователей, токены или пароли.
