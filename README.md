# GOST DOC

Веб-приложение для базового оформления `.docx` по техническому профилю ГОСТ 7.32–2017.

## Что реализовано

- Импорт DOCX и экспорт исправленного DOCX.
- Профиль Times New Roman 12 пт, интервал 1,5, A4, красная строка 1,25 см, поля 30/15/20/20 мм.
- Пользовательский профиль.
- Упрощённый учебный титульный лист (НЕ официальный бланк отчёта НИР).
- Поле автоматического оглавления Word. Для заполнения следует обновить поле в Word.
- Проверка базового оформления, сохранение структуры текста и таблиц.
- Текстовое сравнение до и после и список ограничений.

## Запуск локально

На Mac или Windows потребуется Python 3.11+.

```bash
python3 -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
python -m pip install -r requirements.txt
streamlit run app.py
```

Открой `http://localhost:8501`, если браузер не открылся автоматически.

## Тесты

## Публикация в Streamlit Community Cloud

1. Репозиторий `kimoto2k/GOST-DOC` создан приватным.
2. Подключи GitHub к [Streamlit Community Cloud](https://share.streamlit.io/).
3. Нажми Create app, выбери репозиторий `kimoto2k/GOST-DOC`, ветку `main` и файл `app.py`.
4. После успешного запуска включи публичный доступ в настройках Sharing. Streamlit предоставит ссылку на приложение.

Возможность работы с приватным репозиторием зависит от выданных Streamlit прав на GitHub.

## Безопасность и ограничения

При публикации файл загружается на сервер Streamlit и обрабатывается там. Это НЕ локальная обработка! Не загружайте документы с конфиденциальными или персональными данными до реализации нужной политики и защиты.

Проверка не подтверждает полное соответствие ГОСТ: не проводится визуальная проверка формул, изображений, сносок, сложных таблиц, библиографии и всех структурных элементов. Автоматическое распознавание заголовков эвристическое. Желательно использовать стили Word «Заголовок 1–3».

Источник: [ГОСТ 7.32–2017](https://ifap.ru/library/gost/7322017.pdf), разделы 6.1–6.3.

## Быстрый запуск без терминала

На Mac открой `start_mac.command` (при необходимости разреши запуск в настройках безопасности). На Windows запусти `start_windows.bat`. На первом запуске потребуется интернет для установки зависимостей.
