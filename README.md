# GOST DOC

Минималистичное приложение для оформления и проверки Word-файлов (.docx) по
кафедральной методичке МИСИС или отдельному техническому профилю ГОСТ 7.32–2017.
Работает локально или в браузере через Streamlit Cloud. Это независимый студенческий сервис.

## Возможности

- **Один или несколько DOCX (до 10)**: обработка и скачивание каждого результата либо общего ZIP.
- **Проверка до и после**: поля A4, шрифт, размер, интервалы, абзацы, таблицы и прочие доступные технические параметры.
- **Только проверить**: загрузите самостоятельно оформленный DOCX и получите адресные замечания/CSV без изменения файла.
- **Параметры содержимого**: свой профиль с независимыми размерами и интервалами основного текста и таблиц.
- **Аудит CSV**: список замечаний, категорий и мест в документе, удобный для Excel.
- **Сохранение профилей JSON** и импорт собственных параметров.
- **Титульный лист для учебной работы**: упрощённый, не является официальным титулом НИР по приложению А.
- **Автоматическое содержание Word** по заголовкам. Требуется обновить поле при открытии в Word.
- **Текстовое сравнение** до/после и демонстрационный DOCX для проверки сервиса.
- Изменения кода проверяются тестами через GitHub Actions.

## Профиль по умолчанию

По умолчанию выбран **МИСИС · методичка 2024**: A4; Times New Roman, 12 пт;
полуторный интервал; красная строка 1,25 см; поля **30/15/20/20 мм**.
Таблицы: **10 пт, одинарный интервал, слева, отступы и интервалы 0**; расположение
по центру и предпочитаемая ширина 100%, без заливки. Текстовая подпись прямо перед
таблицей — 12 пт / 1,5 без красной строки. Текст непосредственно после таблицы —
6 пт перед абзацем. Никакие колонки, данные или объединения не удаляются.

Отдельно доступны прежний **ГОСТ 7.32–2017** (основной текст и таблицы 12 пт / 1,5)
и **Свой профиль**. Название профиля МИСИС означает набор реализованных технических
правил, а не сертификат полного соответствия. Конкретная кафедра может требовать другое.
Старые JSON-профили из восьми параметров продолжают загружаться. Новые сохраняют
`ruleset`, `table_size`, `table_line_spacing`; для собственных параметров используется `ruleset="custom"`.

Источники: [конспект методички](docs/MISIS_RULES.md),
[матрица реализации и ограничений](docs/COMPLIANCE_MATRIX.md),
[ГОСТ 7.32–2017](https://ifap.ru/library/gost/7322017.pdf).

**Это не полный автоматический нормоконтроль.** В Word вручную проверяются страницы, титульный лист для НИР, рисунки, формулы, сложные таблицы, список источников и структура отчёта. Никакое количество зелёных значков в интерфейсе не заменит просмотр готового DOCX.

Контекстные интервалы/нумерация заголовков и точный кафедральный титульник остаются
следующим этапом. Аудит не рендерит Word: не определяет реальные переносы, шапку по
смыслу и заполнение страницы. Нестандартные условные стили таблиц требуют проверки
в Word. Ширина 100% — свойство XML, а не доказательство отсутствия выхода за поля.
Если опция оформления таблиц выключена, их прямые XML-свойства сохраняются, однако
изменение глобального стиля Normal может влиять на унаследованное оформление.

## Сценарий для студента

1. Выберите профиль МИСИС или собственные параметры в боковой панели.
2. Загрузите до десяти DOCX. Для проверки своей работы включите «Только проверить»
   и нажмите «Проверить оформление»: исходник остаётся неизменным, результат — CSV.
3. Для исправления выберите «Исправить оформление» → «Оформить документ».
4. Скачайте DOCX/ZIP и CSV; просмотрите ручные замечания и готовый документ в Word.

Демонстрационный DOCX во вкладке «Профиль и помощь» содержит намеренные ошибки,
в том числе таблицу с размером 12 пт / интервалом 1,5 вместо требований МИСИС.
Оформление сайта использует палитру [misis.ru](https://misis.ru), сохраняя существующий
Streamlit-интерфейс и собственное название GOST DOC.

[Макет Superdesign](https://p.superdesign.dev/draft/3f718029-c62b-41d9-8053-5b82da972b68).
Скриншоты работающего приложения и проверенные сценарии: [результаты проверки](docs/VERIFICATION.md).

## Установка на Mac / Linux

Требуется Python 3.11 или новее:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Сайт откроется по адресу http://localhost:8501. Для Windows: `.venv\Scripts\activate` вместо `source ...`, либо `start_windows.bat`.

## Тестирование

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q
python -m compileall -q app.py gostdoc
```

## Публикация на Streamlit Community Cloud

1. Открой https://share.streamlit.io/ и авторизуй GitHub.
2. **Create app** → репозиторий `kimoto2k/GOST-DOC`, ветка `main`, файл `app.py`.
3. После успешного запуска настрой Sharing / публичность приложения.
4. Не выкладывай пользовательские документы в репозиторий и не добавляй ключи в исходный код.

При работе в облаке загружаемые документы обрабатываются сервером приложения. Не отправляй конфиденциальные данные без оценки хранения и защиты на стороне хостинга.
