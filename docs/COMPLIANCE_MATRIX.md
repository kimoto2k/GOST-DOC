# Матрица требований МИСИС

Источник: пользовательский PDF «Методические указания к оформлению отчетов по ГОСТ.pdf»,
Москва, 2024, 15 страниц. В этой задаче оригинал PDF прочитан; в Git документ не добавляется.
Это кафедральная методичка, а не полный ГОСТ 7.32–2017.

| Правило → страница PDF | Исходная реализация | Проверка / план исправления |
| --- | --- | --- |
| Отдельные требования МИСИС | Только STANDARD и пользовательский Profile | Добавить именованный MISIS, сохранить общий и пользовательский профили и старые JSON |
| Таблицы: TNR 10, интервал 1, слева, отступы и интервалы 0 → 6 | formatter.py вызывает process_paragraph с основным профилем 12/1.5 | Отдельная обработка ячеек, включая пустые, объединённые и вложенные; регрессии DOCX с повторным открытием |
| Таблица: 100%, по центру, без заливки → 6 | Не меняется и не проверяется | Проверять и исправлять XML предпочитаемой ширины, расположение, прямую заливку; не удалять данные/колонки |
| Название таблицы 12/1.5, слева, без отступа → 6 | Обычный текст с красной строкой | Распознавать подпись непосредственно перед таблицей; оформить и проверить |
| Текст сразу после таблицы: 6 пт перед → 7 | Сбрасывается в 0 | Применять к следующему обычному абзацу; не переделывать заголовки, списки и подписи |
| Шапка, продолжения, запрет колонки № → 6–7 | Только ручное предупреждение | Проверять явные признаки, просить подтвердить смысл шапки; не придумывать подписи/выводы и не удалять колонки |
| Аудит самостоятельного оформления | Нет технических проверок таблиц | Добавить адресные ошибки по таблице/строке/ячейке/абзацу и CSV; проверка не изменяет файл |
| Заголовки: контекстные интервалы и автоматическая нумерация → 4 | Интервалы 0, эвристики, без многоуровневой нумерации | Следующий этап: отдельные XML-тесты; реальные границы страниц требуют рендера |
| Основной текст 12/1.5 и поля 30/15/20/20 → 3, 5 | Базовое форматирование есть | Сохранить, не применять таблицам настройки основного текста |
| Рисунки, подписи, перекрёстные ссылки → 5–6 | Сохраняются, полноценного контроля нет | Ручная проверка; отдельный этап без преобразования формул/картинок в текст |
| Титульник кафедры → 9, 14–15 | Упрощённый шаблон | Сохранить опцию с явным предупреждением; точное воспроизведение отдельным PR |
| Содержание, нумерация страниц → 3, 12–13 | Word TOC/PAGE, не все интервалы и условия методички | Сохранить функции; отдельный этап и обновление полей в Word |
| 25% пустого места, переносы, формулы, библиография → 3, 10–11 | Нет Word/PDF-рендера | Не заявлять автоматическое соответствие; вынести в ручной контроль |

## Границы первой поставки

Приоритет — таблицы, отдельный профиль, проверка без исправления и настройки параметров.
Правки вносятся в существующий Streamlit/python-docx проект. Вёрстка сайта использует
его штатные компоненты, с визуальными мотивами misis.ru; это независимый сервис,
а не официальный сайт университета. Результат автоматического аудита не означает
полного соответствия методичке: финальная проверка в Word обязательна.
