# МИСИС: требования к оформлению отчётов (по предоставленной методичке)

Источник: пользовательский PDF **«Методические указания к оформлению отчетов по ГОСТ.pdf»**, 15 страниц. Внутри: НИТУ МИСИС, Институт информационных технологий и компьютерных наук, кафедра бизнес-информатики и систем управления производством; «Оформление отчетов в Word по ГОСТу», Москва, 2024. Важное различие: это **кафедральные методические указания**, а не полный текст межгосударственного ГОСТ 7.32–2017. Оригинальный PDF в GitHub не прикреплён; здесь передан подробный текстовый конспект с номерами страниц источника.

## 1. Документ — страница 3

- Имя файла по шаблону: `SurnameLatin_Group_DisciplineAbbreviation_WorkType№N.docx`. В источнике пример `Ivanov_BBI-21-1_IKG_PR№1`. Не переименовывать автоматически без входных данных пользователя.
- Поля: слева 3 см; справа 1.5 см; сверху и снизу по 2 см.
- Страницы нумеруются с первой, но номер на первой скрывается, если документ содержит содержание (именно такая оговорка в методичке).
- Не более 25% пустого места на странице. Без рендера Word/PDF автоматически проверить нельзя.

## 2. Заголовки — страница 4

- Times New Roman, 12 пт, полужирный, выравнивание по левому краю.
- Отступы слева/справа 0, первая строка 1.25 см; межстрочный 1.5.
- Интервал 24 пт до и после, в зависимости от положения: в начале страницы перед 0; перед следующим подзаголовком после 0; в тексте перед заголовком 24; перед обычным текстом после заголовка 24.
- Многоуровневая *автоматическая* нумерация: номер у 1.25 см; текст у 1.25 см; после номера пробел. Подзаголовки должны содержать префиксы уровней выше.
- Структурные заголовки «ВВЕДЕНИЕ», «ЗАКЛЮЧЕНИЕ», «СОДЕРЖАНИЕ», «СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ», «ПРИЛОЖЕНИЕ»: по центру, прописными буквами, без подчёркивания и красной строки; без точки в конце.
- Не использовать бессодержательные заголовки типа «Ход работы».

## 3. Основной текст — страница 5

- Times New Roman, **12 пт**, по ширине.
- Отступы слева и справа 0; красная строка 1.25 см.
- Интервал 0 пт до/после, межстрочный 1.5.
- Перед основной частью обязательно указать цель работы. Не вставлять лишнюю теорию без необходимости.
- Нельзя заканчивать раздел рисунком/таблицей: за ним должен быть текст. Сначала объяснение, затем рисунок.
- Для рисунков требуются перекрёстные ссылки Word, а не вручную набранные номера. Пересчёт полей через Ctrl+A, F9.

## 4. Рисунки — страницы 5–6

- Сам рисунок: расположение по центру, без красной строки; не выходит за поля.
- Подпись рисунка: TNR 12 пт, по центру, без красной строки, 0 пт перед/после, интервал 1.5.
- В названии рисунка использовать тире «–», а не дефис «-»; форма `Рисунок 3 – Название`.
- На каждый рисунок должна быть перекрёстная ссылка.

## 5. Таблицы — страницы 6–7

- **Текст в таблице TNR 10 пт**, левый край, без красной строки, 0 пт до/после, **одинарный интервал**.
- Ширина таблицы 100% доступной области, таблица по центру.
- Заголовок/название таблицы: TNR 12 пт, по левому краю, без красной строки, 0 пт до/после, интервал 1.5.
- Таблицы должны иметь шапку, без заливки ячеек и отдельной колонки с порядковыми номерами.
- Для продолжения большой таблицы: `Продолжение таблицы N`; после шапки строка с номерами колонок (примеры на стр. 7).
- После таблицы должен быть текст с интервалом **6 пт перед**.
- Нельзя завершать раздел таблицей/рисунком/списком; нужен вывод. Нельзя вставлять таблицу как изображение.

## 6. Списки — страницы 7–8

- TNR 12 пт, по ширине, без красной строки, 0 пт до/после, интервал 1.5.
- Маркер на 0 см, начало текста на 1.25 см, после номера табуляция.
- Маркер тире (в методичке дан знак «–»). Для вложенных уровней допустимы русские строчные буквы со скобкой, с исключениями; цифры со скобкой допускаются для конкретного количества пунктов.

## 7. Титульный лист — страница 9 (рисунок 7) и страницы 14–15

- На стр. 9 приведён **образец кафедрального титульного листа**: ведомство, вуз, кафедра, тип/номер работы, дисциплина, тема, направление подготовки, семестр, студент/группа/дата/подпись, преподаватель/оценка/дата/подпись, город и год.
- В текущем приложении титульник **не соответствует этому образцу полностью**.
- На стр. 14–15 есть рекомендации Word: отдельный стиль «Титульный лист» и элемент управления содержимым Rich Text с указанным названием/тегом, чтобы защитить титул от глобального изменения стиля. Сложный XML Word поддерживается не полностью в python-docx; не обещать реализацию без тестов в Word.

## 8. Формулы, приложения, источники — страницы 10–11

- Формулы — нативные объекты Word, не картинки; на отдельной строке по центру, номер арабскими цифрами в круглых скобках справа. Пояснение символов начинается с «где» без двоеточия.
- Приложения с новой страницы, заголовок по центру; обозначения кириллическими буквами (с исключениями), ссылки на приложения в тексте; рисунки/таблицы внутри нумеруются с буквой приложения.
- Список источников: ссылки в тексте в квадратных скобках; описания по ГОСТ. Методичка отдельно требует год издания не старше 5 лет — **это локальное требование методички**, не стоит автоматически переносить его на любой тип работы.

## 9. Содержание — страницы 12–13

- Заголовок должен называться «СОДЕРЖАНИЕ», не «Оглавление»: TNR 12 пт, прописные, полужирные, по центру, без красной строки, до 0 пт, после 24 пт, межстрочный 1.5.
- Записи содержания: TNR 12 пт, левый край, 0 пт до/после, межстрочный 1.5.
- Отступ по уровням: уровень 1 — 0 см; уровень 2 — 0.62 см; уровень 3 — 1.25 см; далее +0.625 см за каждый уровень. Первая строка без дополнительного отступа.

## Автоматизация: критерии принятия

### Реализуемые проверки без рендера
- Стиль основной части, интервалы, поля, размер страницы.
- Тип/размер шрифта в таблицах, интервалы и выравнивание.
- Наличие и оформление подписей в параграфах, если они текстовые.
- Наличие заголовков Word, проверка структурных наименований.
- Частичная диагностика оглавления, нумерации и ссылок на рисунки.

### Только с рендером или ручной проверкой
- Реальные 25% пустого пространства, выход рисунка за поля, перенос страниц.
- Полное совпадение титульного листа с изображением-образцом.
- Настоящее содержание и номера страниц после рендеринга Word.
- Проверка правильности формул, ссылок, библиографических записей и смыслового содержания.
- Автоматическая правильная многоуровневая нумерация с сохранением структуры требует специальных XML-тестов.

**Не замалчивай расхождения между существующим кодом и методичкой.** Сначала подготовь матрицу «правило → место в коде → тест → исправление».
