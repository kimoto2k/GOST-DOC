Добавлены `gostdoc/misis_2024.json` (критерии со страницами и SHA-256 PDF),
`docs/IMPLEMENTATION_CONTRACT.md`, собственное имя результата, Helvetica Bold,

заголовков становятся полями автоматической нумерации, текстовые ссылки не переписываются.

входа, API не предоставил доступ. Для приёмки точного титульника нужен доступный эталон;
его текст/персональные данные нельзя переносить в публичный репозиторий.
